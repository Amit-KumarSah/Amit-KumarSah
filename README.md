## How I think about AI products

I care less about flashy demos and more about whether AI helps a real user complete a real task inside a real workflow.

The questions I come back to:

- Who is the user?
- What decision or action are they trying to complete?
- What systems, data, and policies does the agent need?
- What should the agent be allowed to do?
- When should a human approve the action?
- How do we know the answer is accurate, useful, and grounded?
- What metric proves the product is working?
- What happens when the agent is wrong?
- How does the workflow improve after launch?

My bias is to start with the workflow, not the model. The model matters, but the product system around it is what makes AI useful in enterprise settings.
